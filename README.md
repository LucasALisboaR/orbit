# Orbit 🪐

**Orbit é uma plataforma de organização pessoal criada para centralizar finanças, estudos, tarefas, metas e hábitos em um único lugar.**

O projeto nasceu de uma necessidade real: ter uma ferramenta que ajude a organizar diferentes áreas da vida e, ao mesmo tempo, acompanhar de forma visual o progresso pessoal ao longo do tempo.

Além de ser uma aplicação de uso pessoal, o Orbit também funciona como meu principal laboratório de aprendizado e evolução de **Full Stack Development**, combinando **Angular moderno no frontend** e **Java + Spring Boot no backend**.

## 🚀 Objetivos

* Centralizar informações pessoais em uma única plataforma.
* Facilitar o controle financeiro e visualização de gastos.
* Organizar estudos, sessões de aprendizado e progresso.
* Gerenciar tarefas, projetos, metas e hábitos.
* Criar dashboards com métricas e visualizações úteis.
* Explorar arquitetura, boas práticas e desenvolvimento de aplicações Full Stack.

## 🛠️ Stack

**Frontend**

* Angular
* TypeScript
* RxJS
* Signals

**Backend**

* Java
* Spring Boot
* Spring Data JPA
* Spring Security

**Database**

* PostgreSQL

**DevOps / Infraestrutura**

* Docker
* GitHub Actions
* AWS

> O projeto está sendo desenvolvido de forma incremental. A arquitetura e a stack podem evoluir conforme novas necessidades e conceitos são incorporados ao projeto.

## 📚 Projeto de aprendizado

O Orbit não foi criado apenas como um projeto de portfólio. Cada etapa é utilizada para estudar e aplicar conceitos de desenvolvimento de software, desde fundamentos de backend e frontend até arquitetura, testes, segurança, CI/CD e cloud.

A proposta é **aprender construindo**, pesquisando e tomando as decisões técnicas durante o desenvolvimento, em vez de seguir uma implementação pronta.
